# 05 — Requirements decision register

Status: living · v0.1 · <YYYY-MM-DD>

> **Essentials** — Every requirements choice and every question about *what*
> <Project name> must do lives here. Records use the `DEC-NNN` prefix. A requirement
> links to the real example that motivates it (`40-examples/`, one file per example) and
> to the dated source report it comes from (`50-sources/<date>-<source>.md`); personal
> data stays out of git (the instance's data-regime record). Project-level choices go to
> [`governance/05-project-decisions.md`](../governance/05-project-decisions.md) (`PD-NN`),
> technical design to [`design/05-design-decisions.md`](../design/05-design-decisions.md) (`DD-NN`).
> The "Who decides" column follows [roles and go-aheads](../governance/10-roles-and-go-aheads.md).
